# Package index

## All functions

- [`coefficient_to_variable()`](https://patrickthoral.github.io/baitlist/reference/coefficient_to_variable.md)
  : Converts apollo coefficient_name (b\_) to variable name.
- [`compare_models()`](https://patrickthoral.github.io/baitlist/reference/compare_models.md)
  : Compare feature importance of models using the Wald test
- [`create_criteria_table()`](https://patrickthoral.github.io/baitlist/reference/create_criteria_table.md)
  : Create Criteria table
- [`create_group_comparison_table()`](https://patrickthoral.github.io/baitlist/reference/create_group_comparison_table.md)
  : Create group comparison table
- [`create_model_weights_tables()`](https://patrickthoral.github.io/baitlist/reference/create_model_weights_tables.md)
  : Create Model Weights tables
- [`fit_bait_binary()`](https://patrickthoral.github.io/baitlist/reference/fit_bait_binary.md)
  : Fits the responses in a BAIT binary logistic regression model for
  each respondent group
- [`fit_bait_multinomial()`](https://patrickthoral.github.io/baitlist/reference/fit_bait_multinomial.md)
  : Fits the responses in a BAIT multinomial logistic regression model
  for each respondent group
- [`load_responses()`](https://patrickthoral.github.io/baitlist/reference/load_responses.md)
  : Load responses Reads data from the data/responses.xlsx file for
  specific groups or all if not specified.
- [`maximum_utility_contribution()`](https://patrickthoral.github.io/baitlist/reference/maximum_utility_contribution.md)
  : Calculate relative importance using maximum utility contribution.
- [`plot_group_comparison()`](https://patrickthoral.github.io/baitlist/reference/plot_group_comparison.md)
  : Plots group comparison of coefficient weights
- [`plot_relative_importance()`](https://patrickthoral.github.io/baitlist/reference/plot_relative_importance.md)
  : Plot Relative Importance
- [`predict()`](https://patrickthoral.github.io/baitlist/reference/predict.md)
  : Predict choice based on patient characteristics and family values
- [`standardized_coefficients()`](https://patrickthoral.github.io/baitlist/reference/standardized_coefficients.md)
  : Calculate feature importance using standardized coefficients
