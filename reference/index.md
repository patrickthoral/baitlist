# Package index

## All functions

- [`compare_models()`](https://patrickthoral.github.io/baitlist/reference/compare_models.md)
  : Compare feature importance of models using the Wald test

- [`create_criteria_table()`](https://patrickthoral.github.io/baitlist/reference/create_criteria_table.md)
  : Create Criteria table

- [`create_group_comparison_tables()`](https://patrickthoral.github.io/baitlist/reference/create_group_comparison_tables.md)
  : Create group comparison table

- [`create_model_weights_tables()`](https://patrickthoral.github.io/baitlist/reference/create_model_weights_tables.md)
  : Create Model Weights tables

- [`create_pooled_group_comparison_tables()`](https://patrickthoral.github.io/baitlist/reference/create_pooled_group_comparison_tables.md)
  : Create pooled group comparison table (interaction models)

- [`feature_importance()`](https://patrickthoral.github.io/baitlist/reference/feature_importance.md)
  : Calculates feature importance for all BAIT model types and groups
  using standardized coefficients and maximum utility contribution.

- [`feature_importance_all()`](https://patrickthoral.github.io/baitlist/reference/feature_importance_all.md)
  : Calculates feature importance for all BAIT model types and groups
  using standardized coefficients and maximum utility contribution.

- [`fit_bait_binary()`](https://patrickthoral.github.io/baitlist/reference/fit_bait_binary.md)
  : Fits the responses in a BAIT binary logistic regression model for
  each respondent group

- [`fit_bait_multinomial()`](https://patrickthoral.github.io/baitlist/reference/fit_bait_multinomial.md)
  : Fits the responses in a BAIT multinomial logistic regression model
  for each respondent group

- [`fit_pooled_interaction_binary()`](https://patrickthoral.github.io/baitlist/reference/fit_pooled_interaction_binary.md)
  :

  Fits a pooled binary model with interaction effects using data from
  both `group1` and `group2` to allow comparing difference in
  coefficients between groups

- [`fit_pooled_interaction_multinomial()`](https://patrickthoral.github.io/baitlist/reference/fit_pooled_interaction_multinomial.md)
  :

  Fits a pooled multinomial model with interaction effects using data
  from both `group1` and `group2` to allow comparing difference in
  coefficients between groups

- [`fit_pooled_models()`](https://patrickthoral.github.io/baitlist/reference/fit_pooled_models.md)
  : Fit pooled models with interaction effects for group-wise
  comparisons to allow comparing coefficients for Amsterdam UMC vs. OLVG
  and Intensivists vs. Fellows for both binary and multinomial models

- [`load_responses()`](https://patrickthoral.github.io/baitlist/reference/load_responses.md)
  : Load responses Reads data from the data/responses.xlsx file for
  specific groups or all if not specified.

- [`maximum_utility_contribution()`](https://patrickthoral.github.io/baitlist/reference/maximum_utility_contribution.md)
  : Calculate feature importance using maximum utility contribution.

- [`plot_group_comparison()`](https://patrickthoral.github.io/baitlist/reference/plot_group_comparison.md)
  : Plots group comparison of coefficient weights

- [`plot_pooled_group_comparison()`](https://patrickthoral.github.io/baitlist/reference/plot_pooled_group_comparison.md)
  : Plots group comparison of coefficient weights

- [`plot_relative_importance()`](https://patrickthoral.github.io/baitlist/reference/plot_relative_importance.md)
  : Plot Relative Importance

- [`predict()`](https://patrickthoral.github.io/baitlist/reference/predict.md)
  : Predict choice based on patient characteristics and family values

- [`run_linearity_tests()`](https://patrickthoral.github.io/baitlist/reference/run_linearity_tests.md)
  : Runs linearity tests for multi-level ordered categories.

- [`standardized_coefficients()`](https://patrickthoral.github.io/baitlist/reference/standardized_coefficients.md)
  : Calculate feature importance using standardized coefficients

- [`wald_interaction()`](https://patrickthoral.github.io/baitlist/reference/wald_interaction.md)
  : Creates a dataframe containing the Joint Wald test and Wald tests
  for individual coefficients in a pooled interaction model of two
  groups
