# Compare feature importance of models using the Wald test

Uses the Wald test to pairwise compare features in both models. The Wald
test is defined as \\W = \frac {(\beta\_{1} - \beta\_{2})
^2}{\operatorname {se}(\beta\_{1})^2 + \operatorname {se}(\beta\_{2})^2}
\\

## Usage

``` r
compare_models()
```
